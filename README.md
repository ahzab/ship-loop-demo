# ship-loop-demo

A deliberately small TypeScript project that [ship-loop](https://github.com/ahzab/ship-loop) works on in public. Its issues are real tasks, and its pull requests were opened by ship-loop: an agent wrote the change in an isolated worktree, the gates below had to pass, and the PR records the risk score and gate results.

```sh
npm ci && npm run typecheck && npm test
```
